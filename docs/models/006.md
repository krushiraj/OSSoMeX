# OSSoMeX 006 model card

Experimental software-name extraction POC and the starting point for the interactive demo. Scores are uncalibrated; predictions require review.

## Intended use

Extract explicit software names and versions from research text, then propose local version associations, author intent, sentiment and aliases. Tools, libraries, modules and programming languages are in scope; individual functions, methods and classes are outside scope. This model does not resolve software names to repositories or registry identifiers.

## Model identity

- Pipeline: `scibert-full-label-006`.
- Manifest SHA-256: `fe92420fff8a57b078c3b210fc5312c1a65d599dfc850a479ce266dafb689f8d`.
- Base: `allenai/scibert_scivocab_cased`, revision `ddf0be025f8e432a1870e34811997ba6725bf04a`.
- Stages: detector-005-wordpiece, linker-004, intent-003, sentiment-003 and alias-003.
- Decoder: `wordpiece-bio-v1`; optional boundary repair is disabled.

Each stage has its own encoder. Preserve the sibling checkpoint layout described in [model installation](README.md).

## Training

The training snapshot contains 161 passages from 21 train-reserved CC-BY-4.0 papers, with 164 software names and 47 version spans. Eleven passages carry prior human review; 150 have provisional agent annotations. The data-manifest SHA-256 is `c0b9a74596eb226ffe1ed8331544d8787ce17589f1dd4e1ada87e6f8752c0946`.

Stages were trained from the pinned base with seed 42, ten epochs, learning rate 0.00005, microbatch two and gradient accumulation 16. Each stage made 100 optimizer steps with 3,200 sampled draws. Selection used the final epoch rather than development-set checkpoint selection. No synthetic example or evaluation snippet entered this training snapshot.

Rare attributes have limited support: creation and sharing positives span two and one papers respectively; positive aliases span two papers. Positive, negative and mixed sentiment supervision each spans at most two papers. These fields require broader independent evaluation.

## Evaluation and limitations

006 was selected for software-name extraction in a local POC, not as the best model across every field. On the provisional fresh30 comparison it achieved 74.2% exact-name F1, versus 68.2% for 007 and 36.9% for the installed Wapiti baseline under that experiment's scoring rules. These historical numbers are not interchangeable with the newer [012 three-model benchmark](../research/benchmark-012.md).

006 can miss software mentions, create spurious version associations and produce incorrect attributes. See the [006/012 context-sensitive regression](../research/detector-regression.md). Selected examples and provisional labels do not establish generalization. Inference scores are uncalibrated.
